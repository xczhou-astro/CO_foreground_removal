# CO_foreground_removal

Relevant Code for "Foreground Removal of CO Intensity Mapping Using Deep Learning"
Paper link: https://academic.oup.com/mnras/article/521/1/278/7055955

## dataset

Dataset includes scripts for generating and standardizing of CO line intensity maps and foregrounds

## utils

Utils includes scripts for calculation of power spectra and plotting

## train

Train includes scripts of U-Net and training procedures
